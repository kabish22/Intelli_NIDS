How to use

  1. Pick your Wi-Fi / Ethernet adapter and press Start live capture (needs Administrator).
  2. Browse normally: the threat level should stay Normal.
  3. Press Self-test to scan a device on your own network (your router is pre-filled) and watch a Port Scan (rule) alert appear.
  4. Click any alert row to see why it fired: addresses, packets, the model's top guesses and the flow's measurements.
  5. No live attack? Use Analyse a PCAP file to replay a saved capture.
  6. Use the sliders to tune sensitivity, and Export CSV to save the alerts for your report.

Good to know

  • The ML model was trained on 2017 lab traffic, so it sometimes flags normal traffic. The "ignored" counter shows flows that looked suspicious but were too weak or too small to alert on.
  • The model alone does not notice port scans well, so a behaviour rule covers them.
  • Traffic content is not inspected (encrypted); only flow statistics are used. Only monitor and test networks you own.
